# FREEPORT

**The free coding agent.** No subscription. No configuration. Start in seconds.

An AI coding agent that runs in your terminal — describe what you want, and FREEPORT edits your code.

## Install

```bash
npm install -g FREEPORT
```

## Usage

```bash
cd ~/my-project
FREEPORT
```

## Project Structure

```
FREEPORT/
├── cli/       # CLI build & npm release files
└── web/       # FREEPORT website
```

## Building from Source

```bash
# From the repo root
bun FREEPORT/cli/build.ts 1.0.0
```
